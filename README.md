# SoundTag

NFCタグをかざして、Bluetoothスピーカーの接続先を切り替えるAndroidアプリです。
接続用と全切断用のタグをアプリから作成できます。操作するのは、自動操作を許可した機器だけです。
アカウント、サーバー、NFC Toolsなどの別アプリは必要ありません。

## 必要なもの

- Android 17以降で、NFCとBluetoothに対応する端末。
- 端末とペアリング済みのBluetoothスピーカー。
- 上書きしてよい、書込み可能なNDEFタグ。AndroidでNDEF形式にフォーマットできるタグも使えます。

## インストール

[最新リリース](https://github.com/miyabisun/SoundTag/releases/latest)のAssetsから
`SoundTag-vX.Y.Z.apk`をダウンロードし、端末で開いてインストールします。
提供元の許可を求められたら、Androidの案内に従ってください。
PCから導入する場合や端末でAPKを開けない場合は、[ADBでのインストール](docs/development.md#adbでのインストール)を参照してください。

配布APKは開発用のdebug署名です。ファイルの検証と更新の注意点も、上記のADB導入手順で説明しています。

## 最初の設定

1. Androidの設定でBluetoothとNFCをONにし、スピーカーをペアリングします。
2. SoundTagを開き、「付近のデバイス」へのアクセスを許可します。
3. 一覧で操作したい機器の「自動操作を許可」をONにします。
   Androidの確認画面で対象機器を選び、関連付けを許可してください。
4. 「通知を設定」から、接続状態の変化を知らせる通知を許可します。

機器が確認画面に出ない場合は、電源・距離・ペアリングと端末の位置情報サービスを確認してください。
「自動操作を許可」は操作対象を選ぶ設定で、その場でスピーカーへ接続する操作ではありません。

## タグを作って使う

| 作るタグ | SoundTagでの選択 | 読み取ったときの動作 |
| --- | --- | --- |
| 特定の機器への接続 | 許可した機器の名前を押す | 許可済みの他の機器を切断してから、選んだ機器へ接続 |
| 全て切断 | 「全て切断」を押す | 自動操作を許可した機器をすべて切断 |

1. 操作と対象を確認し、「タグに書き込む」を押します。**タグの既存内容は上書きされます。**
2. タグを端末背面のNFC読取り位置へ近づけ、結果が出るまで動かさずに待ちます。
3. 「書き込みました」と表示されたらタグを離し、「タグを離して戻る」を押します。
4. SoundTagの画面を閉じ、画面ロックを解除した状態でもう一度タグをかざします。

書込み中は、タグに保存されていた接続・切断操作を実行しません。
接続先がすでに接続済みなら、その接続を維持します。許可していない時計などは操作せず、
Bluetooth全体もOFFにしません。

## 通知

タグを読むと、SoundTagの設定画面を開かずに接続操作を行います。
実際に接続状態が変わった場合だけ、結果をAndroidの通知へ表示します。
状態が変わらない再タッチや失敗では通知せず、一部変更後に失敗した場合はその旨を通知します。

通知が動画などの表示を妨げる場合は、「通知を設定」からAndroid側の
「接続状態の変化」をサイレントにしてください。端末によっては「マナー」などの名称です。
通知を無効にしても接続操作は使え、タグを読むたびに許可画面を開くこともありません。
OSが表示する処理中の通知は結果通知とは別で、操作が終わると消えます。

## YouTubeの画面復帰

タグ読取りでYouTubeが小窓になる場合は、「画面復帰を設定」から
Androidの「通知へのアクセス」を許可すると、再生中のYouTubeへ自動で戻ります。
一時的な縮小は発生します。YouTube Music、停止中・一時停止中のYouTubeは対象外です。

この設定は任意で、解除も同じ画面から行えます。再生状態の確認に使い、通知本文は読み取り・保存しません。

## うまく動かないとき

- **タグを読んでも動かない**：NFCとBluetoothをONにし、画面ロックを解除してください。
  初回インストール後とアプリの強制停止後は、先にSoundTagを手動で開く必要があります。
- **以前のタグで接続できない**：機器の電源とペアリング、「自動操作を許可」を確認してください。
  許可をOFFにした機器は、以前作ったタグからも操作できません。
- **書込みに失敗する**：表示された理由を確認し、タグを離してから再試行してください。
  読取専用・非対応・容量不足のタグには書き込めません。タグをロックする機能はありません。
- **書込みを中断した**：画面を離れると書込みは中止され、自動再開しません。
  元の内容へ戻る保証はないため、タグの内容を確認してから書き直してください。
- **接続したのに音が出ない**：再生アプリの再生状態と出力先を確認してください。
  一時停止していたら手動で再開してください。SoundTagは再生を強制しません。

旧版の指定機器切断タグも引き続き利用できます。
ビルド、モック検証、タグ形式については[開発ガイド](docs/development.md)を参照してください。
